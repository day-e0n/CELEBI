계층 구조
  [1] 쿼리   Init -> Planning -> Executing -> Exit        쿼리 하나당 1개
  [2] 태스크 Created -> Queued -> Routing -> Reserving ->  쿼리 하나가 여러 개로
             [Downgrading] -> Preparing -> Computing ->    쪼개져 동시 실행
             Finalizing -> Exit
  [3] 연산자 Computing 구간이 어느 연산자였는지

숫자 두 개를 함께 적는 이유
  합계     = 그 상태에 있던 모든 것의 시간을 더한 값
  겹침제거 = 같은 시각에 겹친 구간을 한 번만 센 값 (실제로 흐른 시간)
  동시     = 합계 / 겹침제거. 평균 몇 개가 동시에 그 상태였는가
